# Priority Issues
- **[P2] Floating Widget Clutter and Overlaps**:
  - *Why it matters*: The simultaneous presence of a large speed-dial floating bar (5 options), a separate `ChatbotWidget`, and a header "Tư vấn ngay" button creates choice paralysis and covers valuable screen space, especially on mobile.
  - *Fix*: Integrate the chatbot launcher as an item in the speed-dial menu or auto-collapse floating widgets when the chatbot is open.
  - *Suggested command*: `/impeccable layout`
- **[P2] Button Geometry Inconsistencies**:
  - *Why it matters*: Rectangular sharp buttons (`rounded-none`) on the hero, company info, and news filters clash visually with rounded buttons (`rounded-md` / `rounded-[8px]`) in forms, services detail cards, and select dropdowns.
  - *Fix*: Unify button styling across all components to either fully rectangular or consistent rounded borders.
  - *Suggested command*: `/impeccable layout`
- **[P2] React State Routing and Browser History**:
  - *Why it matters*: Using conditional React state to switch pages (`currentView`) prevents standard browser back/forward history tracking. Clicking the browser back button exits the website instead of returning to the previous catalog view.
  - *Fix*: Integrate hash-based routing (`#home`, `#services`) or query parameters to link active views to browser history.
  - *Suggested command*: `/impeccable adapt`
- **[P3] Concurrent Animation Overload**:
  - *Why it matters*: Having background particle movement, an auto-scrolling news ticker marquee, and sliding hero carousels operating simultaneously on the home screen increases extraneous cognitive load.
  - *Fix*: Reduce auto-carousel speed, pause the marquee scroll on mouse hover, and provide a toggle to disable the particle background.
  - *Suggested command*: `/impeccable animate`

# Persona Red Flags
- **Jordan (Confused First-Timer)**: The homepage presents multiple competing CTA elements ("Tư vấn ngay" in header, master FAB headphones trigger, and the speed-dial Zalo/hotline/chatbot items). This density of contact options creates decision paralysis. Jordan may feel overwhelmed figuring out the difference between the "AI Chatbot" and "Tư vấn ngay".
- **Alex (Impatient Power User)**: Alex attempts to search for a specific solution, finds it, and clicks through. When they try to navigate back to the list using the browser's back button, they exit the site entirely because state-based routing is not synchronized with the browser history.
- **Sam (Accessibility-Dependent User)**: Focus states for input text areas and navigation dropdown items rely on default browser behavior and lack distinct custom visual indicators. Custom selectors and overlays (like the speed-dial FAB list) do not have ARIA labels or keyboard-navigable options, making them keyboard traps.
