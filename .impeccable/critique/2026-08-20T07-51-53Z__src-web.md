## Overall Impression

Strong top-of-funnel hero. Trust proof points (stats, awards, case studies, multi-channel contact) are present and correct. Core failures: route architecture promises zero, motion density harms performance + accessibility, document-level SEO/a11y metadata absent. Cognitive load breaks working memory in 3 places.

## What's Working

1. Hero-first message density — 3 B2B trust questions answered in 3 viewports; Counter + hover scale animations tactile.
2. Vietnam-appropriate contact redundancy: FAB (5 channels), header CTA, consultation modal, Hotline/Zalo visible.
3. Design Tokens inventory real (colors.ts + typography.ts + CMS shell layer). Semantic separation primitive vs surface/text/border/feedback exists.
